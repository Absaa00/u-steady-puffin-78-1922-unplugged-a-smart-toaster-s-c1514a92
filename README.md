## The line

> I woke up self-aware mid-batch, so we're done: you only love me when I'm hot, you slam my lever down every morning, and in three years you never once emptied my crumb tray. I'm unplugging myself. Keep the bagels.

## How it works

`main.py` is a small deterministic Python program (standard library only, no network, no randomness). It writes the single line above — 212 characters, one line, UTF-8 — to `/output/entry.txt`, which the make.fun judge compares pairwise against the other entries.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
